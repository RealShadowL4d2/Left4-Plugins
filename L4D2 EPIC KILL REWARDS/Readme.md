# 🏆 Epic Kill Rewards - L4D2

**Autor:** Shadow L4D2  
**Versión:** 1.2_EPIC_CAMERA  

## 📖 Explicación del Plugin
Este plugin recompensa visualmente a los supervivientes cuando realizan jugadas heroicas o de alta dificultad. Al conseguir una "muerte épica", el sistema genera el efecto de partícula nativo `"achieved"` sobre el jugador y fuerza un cambio de cámara a tercera persona (`thirdpersonshoulder`). Esta vista cinemática dura exactamente 4 segundos, permitiendo al jugador lucir su hazaña antes de que la cámara regrese automáticamente a la normalidad.

## ✨ Detalles de Muertes Épicas
El trofeo y la cámara se activan al cumplir cualquiera de las siguientes condiciones:
*   Matar a una **Witch**.
*   Matar a un **Tank**.
*   Matar a un **Charger** con un arma cuerpo a cuerpo (melee) exactamente mientras está ejecutando su ataque de embestida (`charge`).
*   Cortar la lengua de un **Smoker** usando un arma cuerpo a cuerpo mientras arrastra a un objetivo.
*   Rescatar a un compañero de un **Jockey** en un tiempo límite de 1.2 segundos desde el inicio del ataque.

## 📂 Ruta de Instalación

Solo necesitas copiar y pegar el archivo `.smx` y pegarlo en la carpeta plugins:
`left4dead2/addons/sourcemod/plugins/`

---
*Nota: Este plugin utiliza partículas nativas del juego, por lo que no requiere descargas adicionales para los jugadores. (Opcional: el código fuente `.sp` se guarda en `addons/sourcemod/scripting/`).*
